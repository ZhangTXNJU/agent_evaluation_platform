# 旅行规划自治 Agent 项目总结

## 1. 项目简介
本项目是一个专注于旅行规划场景的**自治智能体（Autonomous Agent）**。系统基于自然语言交互，能够自主理解用户需求、调用外部工具获取真实数据，并在多轮思考与执行中不断修正和完善旅行计划。本平台不仅实现了与用户的自然对话，还在核心逻辑上引入了长短期记忆与双重推理框架，使其具备更强的环境适应性和决策能力。

## 2. 混合推理架构设计：Plan-and-Execute + ReAct
为了解决复杂旅行规划中“全局视野缺失”和“单步执行死板”的问题，我们在 Agent 核心引入了两种推理框架的融合：
- **Plan 阶段 (Plan-and-Execute)**：在接到用户指令后，Agent 首先独立调用 LLM 进行“宏观规划（Planning）”。在此阶段，Agent 依据长短期记忆生成一份粗略的每日行程大纲（High-level Plan），而不是立刻盲目陷入细节。
- **Execute 阶段 (ReAct 循环)**：在宏观计划的指导下，Agent 进入 `Thought -> Action -> Observation` 的 ReAct 循环。它根据当前的微观需求自主选择调用哪些外部工具（如搜索景点、查询天气等），并根据工具返回的结果动态调整自己的短期记忆与下一步动作。当发现环境变化或信息充足时，Agent 会利用 `converge` 动作主动结束循环并输出最终计划。

## 3. 长短期记忆机制
为了让 Agent 像人类一样拥有经验积累，我们设计了双层记忆机制：
- **短期记忆（Short-term Memory）**：记录当前会话（Session）内的对话上下文、推理轨迹（Thought/Plan）、工具调用（Tool Call）及观测结果（Observation）。这使得 Agent 能在 ReAct 循环中维持上下文连贯性。
- **长期记忆（Long-term Memory）**：跨会话持久化存储用户偏好与过往的成功规划结果（以 JSONL 形式落盘）。每次新规划前，Agent 会利用检索模块调取相关的历史经验，实现“越用越聪明”。

## 4. 外部工具的组装与调用
目前 Agent 已成功集成了以下真实（或模拟）能力的工具模块：
1. **景点搜索 (search_attractions)**：对接高德/百度/Google等API获取景点位置与评分。
2. **天气查询 (query_weather)**：预测行程期间的天气变化，供 Agent 规避恶劣天气。
3. **交通计算 (calculate_distance)**：评估景点间的通行时间和距离。
4. **预算与汇率 (calculate_budget, get_exchange_rate)**：动态计算总消费，确保不超支。

> **注**：在开发和演示阶段，平台提供了 `MOCK_MODE=true` 环境变量，允许在无 API Key 的情况下通过沙盒数据完成完整的调用流演示。

## 5. 评估与运行追踪
为方便开发团队与评估平台对 Agent 的决策质量进行指标分析：
- **可视化日志 (Trace)**：系统内定义了标准的 `TraceEvent`，详细记录了每个动作的耗时、来源和内容，并在 CLI 中以友好的前缀（如 `[思考]`、`[工具调用]`、`[观察]`）实时展示。
- **离线评估文件**：每轮会话完成后，完整的执行 Trace 和最终规划结果将自动被追加写入至 `data/eval_records.jsonl` 中，便于后续编写自动化脚本评估 Agent 的步数、工具调用准确率以及最终计划的合理性。

## 6. 快速演示指南
进入 `agent` 目录并使用虚拟环境运行：
```powershell
# 1. 激活虚拟环境
.\.venv\Scripts\Activate.ps1

# 2. （可选）验证配置与网络连通性
python healthcheck.py

# 3. 启动交互式终端
python cli.py
```
> **输入示例**："帮我规划一个南京2日游，预算1500，我喜欢历史和夜景。"
